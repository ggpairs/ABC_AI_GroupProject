# ABC数字创造营小程序

ABC数字创造营分社官方微信小程序，定位为轻量级线上官网，面向潜在志愿者（大学生/职场人）与潜在客户（企业/组织），提供品牌展示、案例沉淀与双端引流核心功能。

## 功能特性

### 核心功能
- **首页**：品牌展示、分社简介、精选案例、双CTA按钮、招募季动态
- **案例页**：案例列表、分类筛选、案例详情、收藏功能
- **志愿者页**：项目季招募、我的申请入口、申请Q&A、志愿者故事
- **成为客户页**：服务介绍、合作流程、精选案例、立即申请
- **我的页**：用户信息、收藏列表、关于我们、退出登录

### 技术特性
- 微信授权登录 + 用户名密码登录
- 收藏功能（案例、志愿者故事）
- 分享功能（案例详情、志愿者故事详情）
- 跳转ABC总站小程序（志愿者报名、客户申请）
- 招募季动态展示（根据时间自动切换）
- 响应式设计，适配移动端

## 技术栈

- **前端框架**：Taro + React + TypeScript
- **样式方案**：Tailwind CSS
- **后端服务**：Supabase（数据库 + 认证 + Edge Functions）
- **图标库**：Material Design Icons (MDI)

## 数据库设计

### 主要数据表
- `profiles`：用户资料表
- `cases`：案例表
- `volunteer_stories`：志愿者故事表
- `recruitment_seasons`：招募季表
- `qa_items`：Q&A表
- `service_modules`：服务模块表
- `favorites`：收藏表

## 配置说明

### 1. 微信小程序配置

需要在Supabase后台配置以下环境变量：

- `WECHAT_MINIPROGRAM_LOGIN_APP_ID`：微信小程序AppID
- `WECHAT_MINIPROGRAM_LOGIN_APP_SECRET`：微信小程序AppSecret

### 2. ABC总站小程序跳转配置

需要修改以下文件中的`wxAPP_ID_HERE`占位符为实际的ABC总站小程序AppID：

- `src/pages/volunteers/index.tsx`（志愿者报名、我的申请）
- `src/pages/clients/index.tsx`（客户申请）

### 3. 初始数据

数据库已预置以下初始数据：
- 5个案例示例
- 4个志愿者故事
- 2个招募季（2026夏季进行中、2026秋季即将开始）
- 8个Q&A问题
- 4个服务模块

## 使用说明

### 首次登录
1. 第一个注册的用户自动成为管理员
2. 管理员可以管理所有内容（案例、志愿者故事、招募季、Q&A等）
3. 普通用户可以浏览内容、收藏案例和故事

### 志愿者报名流程
1. 浏览志愿者页面，查看当前招募季信息
2. 点击"立即报名"按钮，跳转至ABC总站小程序完成报名
3. 通过"我的申请"入口查看申请进度

### 客户申请流程
1. 浏览成为客户页面，了解服务内容和合作流程
2. 点击"立即申请"按钮，跳转至ABC总站小程序完成申请

### 收藏功能
1. 在案例详情页或志愿者故事详情页点击收藏按钮
2. 在"我的"页面查看所有收藏内容
3. 支持取消收藏

## 设计说明

### 色彩系统
- **主色调**：专业的深蓝色（#1E5EBF）- 代表科技感和信任
- **次要色**：青色（#0EA5E9）- 代表创新感
- **强调色**：温暖的橙色（#F97316）- 用于行动号召按钮
- **背景色**：柔和的浅灰蓝色 - 营造专业温暖的氛围

### 设计理念
- 专业与温暖并重
- 简洁直观的交互
- 清晰的信息层级
- 适配移动端的大字体和大按钮

## 开发说明

### 本地开发
```bash
# 安装依赖
pnpm install

# 启动微信小程序开发
npm run dev:weapp

# 启动H5开发
npm run dev:h5

# 代码检查
npm run lint
```

### 构建部署
```bash
# 构建微信小程序
npm run build:weapp

# 构建H5
npm run build:h5
```

## 注意事项

1. **微信小程序跳转**：需要在微信公众平台配置业务域名和服务器域名
2. **图片资源**：所有图片均使用外部CDN链接，不占用小程序包体积
3. **数据管理**：建议使用Supabase后台或开发管理后台进行内容管理
4. **权限控制**：第一个注册用户为管理员，其他用户为普通用户
