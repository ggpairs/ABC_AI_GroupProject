# 需求文档

## 1. 应用概述

- **应用名称**：ABC数字创造营小程序
- **应用描述**：ABC数字创造营分社官方微信小程序，定位为轻量级线上官网，面向潜在志愿者（大学生/职场人）与潜在客户（企业/组织），提供品牌展示、案例沉淀与双端引流核心功能。

---

## 2. 用户与使用场景

### 2.1 目标用户

- 潜在志愿者：大学生、职场人，希望了解项目季招募信息并完成报名引流
- 潜在客户：企业/组织，希望了解服务内容并完成客户申请引流

### 2.2 核心使用场景

- 志愿者浏览招募信息，点击报名按钮跳转至ABC总站小程序完成申请
- 客户浏览服务介绍与合作流程，点击申请按钮跳转至总站客户申请功能
- 用户浏览案例与志愿者故事，收藏感兴趣内容

---

## 3. 页面结构与核心功能

### 3.1 页面总览

```
├── 首页（Home）
│   ├── 导航栏
│   ├── Hero区
│   ├── 分社简介
│   ├── 精选案例入口
│   ├── 双CTA区
│   └── 招募季动态
│
├── 案例页（Cases）
│   ├── 案例列表（分类筛选）
│   └── 案例详情页
│
├── 志愿者页（Volunteers）
│   ├── 项目季招募（动态展示）
│   ├── 我的申请入口
│   ├── 申请Q&A
│   └── 志愿者故事
│
├── 成为客户页（Clients）
│   ├── 服务介绍
│   ├── 合作流程
│   ├── 精选案例
│   └── 立即申请入口
│
└── 我的页（Profile）
    ├── 用户信息
    ├── 我的收藏
    ├── 关于我们
    └── 版本信息
```

### 3.2 首页（Home）

**页面目的**：品牌认知 + 双端引流

| 模块 | 内容 | 交互 |
|------|------|------|
| 导航栏 | Logo + 分社名称 | 固定顶部 |
| Hero区 | 分社Slogan + 核心价值主张 | 背景视频/动态图 |
| 分社简介 | 定位、风格、战略目标（3-4个关键词） | 展开/收起 |
| 精选案例 | 3个代表性项目卡片 | 点击进入案例详情 |
| 双CTA区 | 【成为志愿者】+【成为客户】大按钮 | 分别跳转对应Tab |
| 招募季动态 | 当前招募季倒计时/状态（如：2026夏季招募进行中） | 点击进入志愿者页 |

- 视觉风格：专业、温暖，与ABC总社品牌色保持一致

### 3.3 案例页（Cases）

**页面目的**：建立专业信任，展示转型能力

**案例列表**

| 模块 | 内容 | 交互 |
|------|------|------|
| 筛选栏 | 全部 / AI Bot / AI小程序 / 数字化转型 / 其他 | 点击筛选，列表实时更新 |
| 案例卡片 | 封面图 + 项目名称 + 客户类型 + 标签 | 点击进入详情 |

**案例详情页**

| 字段 | 说明 |
|------|------|
| 项目封面图 | 图片展示 |
| 项目名称 | 文本 |
| 客户行业/类型 | 文本标签 |
| 项目标签 | 技术栈/领域标签 |
| 项目周期 | 文本 |
| 项目简介 | 富文本 |
| 项目背景 | 富文本 |
| 挑战 | 富文本 |
| 解决方案 | 富文本 |
| 成果数据 | 富文本/数据展示 |
| 参与志愿者 | 脱敏展示 |

- 案例详情页支持收藏操作
- 每个案例支持生成分享海报/链接，便于私域传播

### 3.4 志愿者页（Volunteers）

**页面目的**：招募转化 + 降低决策门槛

#### 3.4.1 项目季招募（动态展示）

| 元素 | 内容 |
|------|------|
| 季节Tab | 春季 / 夏季 / 秋季（当前招募季高亮） |
| 招募状态 | 进行中 / 即将开始 / 已结束 |
| 职责要求 | 岗位描述、能力要求、时间投入、收获 |
| 立即报名 | 按钮 → 跳转ABC总站志愿者报名小程序（wx.navigateToMiniProgram） |

**动态逻辑**：
- 根据时间自动切换展示当前招募季
- 非招募期显示：「下次招募预计X月开启，可先收藏」
- 招募季时间、状态、职责要求均由后台CMS配置

#### 3.4.2 我的申请

| 元素 | 交互 |
|------|------|
| 入口 | 卡片式入口，显示申请状态摘要 |
| 跳转逻辑 | 点击 → 直接跳转ABC总站志愿者报名小程序个人中心（wx.navigateToMiniProgram） |
| 状态提示 | 「请在总站小程序查看申请进度」 |

#### 3.4.3 申请Q&A

| 元素 | 内容 |
|------|------|
| 分类 | 报名条件 / 时间投入 / 技能要求 / 项目匹配 / 其他 |
| 展开式问答 | 常见问题折叠展示，点击展开答案 |

示例问题：
- Q：没有技术背景可以申请吗？
- Q：项目季的时间安排是怎样的？
- Q：如何平衡全职工作和志愿者工作？

Q&A内容由后台CMS维护，支持分类添加/编辑。

#### 3.4.4 志愿者故事

| 元素 | 内容 |
|------|------|
| 故事卡片 | 志愿者头像 + 姓名（脱敏）+ 一句话感悟 |
| 详情页 | 完整故事：加入原因、项目经历、成长收获、建议 |
| 筛选 | 按项目季 / 岗位类型筛选 |

- 志愿者故事详情页支持收藏操作
- 每个故事支持生成分享海报/链接

### 3.5 成为客户页（Clients）

**页面目的**：B端获客转化

| 模块 | 内容 | 交互 |
|------|------|------|
| 服务介绍 | 数字化创造营能提供的价值（3-4个服务模块） | 图文卡片展示 |
| 合作流程 | 需求沟通 → 方案匹配 → 项目执行 → 成果交付 | 步骤时间轴 |
| 精选案例 | 精选2-3个B端合作案例 | 点击进入案例详情 |
| 立即申请 | 大按钮 → 跳转总站客户申请功能 | 待定：H5 web-view 或小程序跳转 |

**服务模块**：
- AI应用落地咨询
- 数字化产品原型开发
- 内部流程数字化改造
- 数字化人才培训

### 3.6 我的页（Profile）

**页面目的**：极简个人中心

| 模块 | 内容 | 交互 |
|------|------|------|
| 用户信息 | 微信头像 + 昵称（自动获取） | 无编辑 |
| 我的收藏 | 收藏的案例、志愿者故事 | 点击进入详情，支持取消收藏 |
| 关于我们 | 分社介绍、联系方式 | 跳转首页/弹出客服 |
| 版本信息 | 小程序版本号 | 静态展示 |

## 4. 业务规则与逻辑

### 4.1 登录与用户体系

- 默认提供微信授权登录 + 账号密码登录
- 收藏数据与用户微信openid绑定，独立存储于本小程序，不与总站用户体系强绑定

### 4.2 跳转总站规则

| 功能点 | 跳转目标 | 跳转方式 |
|--------|----------|----------|
| 志愿者-立即报名 | ABC总站志愿者报名小程序 | wx.navigateToMiniProgram |
| 志愿者-我的申请 | ABC总站志愿者报名小程序个人中心 | wx.navigateToMiniProgram |
| 客户-立即申请 | ABC总站客户申请功能（H5/小程序） | 待定：H5 web-view 或小程序跳转 |

- 跳转前需确认ABC总站小程序的appId和跳转路径

### 4.3 收藏功能逻辑

- 收藏内容类型：案例、志愿者故事
- 收藏数据存储：云端存储，与微信openid绑定
- 支持取消收藏
- 收藏状态在详情页与我的收藏列表实时同步

### 4.4 招募季动态逻辑

- 系统根据当前时间自动高亮对应招募季Tab
- 招募状态由后台CMS配置（进行中 / 即将开始 / 已结束）
- 非招募期自动展示提示文案：「下次招募预计X月开启，可先收藏」

### 4.5 分享传播

- 案例详情页、志愿者故事详情页均支持生成分享海报/链接
- 便于用户在私域传播

### 4.6 埋点需求

- 关键转化按钮点击事件需埋点：报名按钮、客户申请按钮、收藏按钮

## 5. 内容管理需求（CMS）

| 内容类型 | 管理需求 | 更新频率 |
|----------|----------|----------|
| 案例 | 后台添加/编辑/上架/下架 | 每季项目结束后 |
| 志愿者故事 | 后台添加/编辑 | 持续收集 |
| 招募季信息 | 后台配置时间、状态、职责要求 | 每季招募前 |
| Q&A | 后台添加/编辑/分类 | 按需更新 |
| 客户页服务介绍 | 后台编辑 | 战略调整时 |

- 建议使用轻量级CMS（如Strapi/云开发）或ABC现有内容中台

---

## 6. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 跳转总站小程序失败 | 提示「跳转失败，请稍后重试」，不崩溃 |
| 当前无任何招募季进行中 | 展示「下次招募预计X月开启，可先收藏」提示 |
| 收藏列表为空 | 展示空状态提示：「暂无收藏内容，去浏览案例或故事吧」 |
| 案例列表为空（筛选结果） | 展示空状态提示：「暂无相关案例」 |
| 用户未授权微信登录 | 收藏功能引导用户授权登录，未登录不可收藏 |
| 网络异常 | 各页面展示通用网络错误提示，支持重试 |
